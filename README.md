# TRAPO by Chunche Labs

*trapo (n.): Spanish for rag. Throw one over your sound.*

TRAPO is an audio effect that works like real cloth. Pick a fabric, choose how many layers,
and hear your sound soften, thicken and breathe. Free during the beta.

- **Website:** https://tavolagos.github.io/trapo
- **Download:** [latest version](https://github.com/tavolagos/trapo/releases/latest) for Mac and Windows (VST3, AU, CLAP, standalone)
- **Something wrong, or an idea?** [Open a report](https://github.com/tavolagos/trapo/issues/new/choose) or write to tavolagoss.beats@gmail.com

This project holds TRAPO's website and its downloads.
